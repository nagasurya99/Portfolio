Ticket Management System

Managing customer support requests manually can lead to delays and lack of transparency. To solve this, I developed a web-based Ticket Management System that allows users to create, purchase, and manage support tickets in real time. The front-end was built using HTML and Python Flask, providing a clean interface for ticket submission and tracking. SQL was used to store structured data such as user profiles and ticket metadata, while MongoDB was integrated to handle dynamic ticket comments and status histories. The system supports ticket prioritization, admin updates, and real-time tracking of issue resolution.

Technologies Used: HTML, Python, SQL, MongoDB

  • Developed a web-based system where users can create, purchase, and manage support tickets.
  • Users can track status, update priorities; SQL stores user data, and MongoDB stores ticket history and comments.

Plant Disease Detection Using Machine Learning & Deep Learning

Early detection of plant diseases is critical for preventing crop loss. I developed a deep learning-based solution that detects diseases from images of plant leaves. A custom image dataset was created, preprocessed, and labeled for classification. Using Convolutional Neural Networks (CNN), the model achieved high accuracy in identifying common diseases, while KNN was used for quick baseline comparisons. The model was trained and evaluated using real-world agricultural images, and the final system included a simple interface where users could upload leaf images and receive a prediction on plant health and potential disease.

Technologies Used: Python, CNN, KNN

  • Designed a database schema to store images of various plant leaves, determining plant life expectancy.
  • Developed an interface to input leaf images and evaluate plant health based on image condition.

Intelligent Car-Port Reservation System Based on IoT

Urban parking issues often result in time and fuel wastage. To address this, I built an IoT-enabled Car-Port Reservation System that allows drivers to reserve parking spaces in advance. Using Raspberry Pi and sensor modules, real-time parking availability was tracked and updated to the cloud. A Python-based web interface was created where users could log in, view available slots, and reserve spots. QR code scanning was implemented for secure entry verification at the gate. The backend also stored registered vehicle data and reservation history for efficient management and analytics.

Technologies Used: Python, IoT, Raspberry Pi

  • Implemented a database schema to store registered vehicle details for availability tracking.
  • Created a UI to reserve parking spots upon mobile login, verifying reservations via QR.
